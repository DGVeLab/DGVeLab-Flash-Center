Advanced operations can permanently erase device settings or install incompatible firmware. Test on a spare ESP board first. Close Arduino Serial Monitor, PlatformIO or other apps using the COM port.
USB connection help & drivers (CP210x · CH340 · CH9102)

If no serial port appears, try a USB data cable, connect the board directly, close other COM-port applications, and check Windows Device Manager. Some boards require holding BOOT while connecting.

Install drivers only when needed, from the manufacturer:

  • Silicon Labs — CP210x VCP
  • WCH — CH340 / CH341
  • WCH — CH9102 / CH343 family

If an automatic reset fails, press EN/RST on the board. Do not disconnect the cable during a flash operation.
